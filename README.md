# fabr

One page, static site for fabr, with a planned pilot at BITS Goa.

## Local preview

From this directory:

```powershell
python -m http.server 5173
```

Open <http://localhost:5173>. The site has no build step or runtime dependencies.

The copy describes the team's intent and north star. It leaves out progress, funding, timelines, and unverified performance claims. The site uses the user supplied illustration with only the lower right watermark area replaced by matching paper.
